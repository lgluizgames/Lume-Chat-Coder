IA instalada no próprio Android

Funciona offline e sem chave de API. Instale um modelo GGUF uma vez e converse sem pagar por mensagem.

Verificando se há um modelo instalado...

Recomendado para código: Qwen2.5-Coder-1.5B-Instruct, versão Q4_K_M (~986 MB). Se estiver lento ou faltar memória, escolha o modelo 0.5B (~398 MB). Ambos são gratuitos.

Os botões abrem a página do modelo no navegador. Depois selecione o arquivo GGUF baixado. O aplicativo não usa internet para responder.

Importar conversas

Aceita conversations.json das exportações do Claude e do ChatGPT, além de backups do Lume Chat. Primeiro extraia o arquivo ZIP no ZArchiver.

Importação local: o arquivo é lido neste dispositivo, sem envio para servidores. Conversas de texto são importadas; anexos originais e algumas mensagens multimídia podem não acompanhar a exportação.
